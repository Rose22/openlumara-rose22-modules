## my personal modules

Some of these were manually coded, some of them were vibecoded. When it comes to user modules, i don't really care, because user modules are fun and vibecoding them is fun too. They are unofficial, not part of openlumara itself, and are basically just plugins anyone can make. As long as the core of openlumara is manually coded and vetted, that's what matters!

These can serve as examples for how to create your own modules. May they inspire you!
