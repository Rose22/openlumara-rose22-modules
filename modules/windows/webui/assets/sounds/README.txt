DROP YOUR SOUND FILES HERE.

The windows extension auto-plays them instead of its synth beeps.
Supported: .mp3, .ogg, .wav, .m4a (mp3 is checked first).
No settings needed - just name the file after the cue and refresh.
(To change files later: rename, hard-refresh. The mute toggle in the
tray silences everything, files included.)

CUE NAMES (exact, lowercase):
  msn-in     incoming Windows Messenger message / nudge
  msn-out    you send a message on MSN
  aim-in     incoming AIM message from xXx_SkateOrDie_xX
  aim-out    you send on AIM
  icq-in     incoming ICQ message from 48291755
  icq-out    you send on ICQ
  irc        any new line in the IRC window (channel + PM)
  room       new line in an MSN Chat Zone room
  room-out   you type in a chatroom
  ad         a popup ad spawns (the classic ding!)
  gaurd      CyberGaurd alert popup appears
  siren      infection stage goes up (plays once per stage)
  bonzo      BonzoBuddy says something / you click him
  web        a page loads in the fake browser

Examples: msn-in.mp3, ad.wav, siren.ogg

Tip: real MSN 7 sounds are named something like msgin.wav / msgout.wav -
just rename them to msn-in.wav / msn-out.wav. ICQ's classic "uh-oh" works
great as icq-in. Keep files short (<2s) unless it's the siren.
