# ambient sound loops

drop your meditation ambience files in this folder — mp3, ogg, wav, m4a,
flac, opus or webm — and they become available to the meditation module
automatically (no restart needed; the track list refreshes with every
overlay poll).

- the AI can start one by name (`ambient on, track rain_on_roof.mp3`) or
  set it to `auto` to gently rotate through every file with soft crossfades
- the sidebar shows how many loops are loaded
- files are served straight to the browser via
  `/ext-assets/meditation/audio/<filename>`
- longer loops are better (2–10 min tiles seamlessly); anything loops
  automatically

suggestions: rain, ocean waves, singing bowls, wind through trees,
brown/pink noise, fireplace crackle.
