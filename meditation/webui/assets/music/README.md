# meditation music

Drop full music tracks in this folder (mp3, ogg, wav, m4a, flac, webm, opus).

They become available to the meditation module as `music_track` on the
`start` and `scene` tools - one track loops for the session, at its own
volume next to the ambient soundscape. 'auto' random-picks one.

Served straight to the browser overlay through /ext-assets/meditation/music/.
